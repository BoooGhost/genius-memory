왜 Genius Memory인가요?

단순한 줄거리 요약을 넘어, TRPG와 다인 시뮬레이션에 필요한 모든 기억 장치를 하나로 통합했습니다.

1+5 계층형 전체 요약 & 자동 숨김

최근 보호 버퍼를 제외한 대화를 요약해 1~5번 조각 슬롯에 채우고, 5개가 모이면 [통합 전체 요약]으로 자동 압축합니다. 요약된 과거 메시지는 자동으로 숨김(유령) 처리되어 토큰을 아껴줍니다.

실시간 다중 사건 감지기 (기록 중 ➔ 완료)

매 턴 가벼운 감지기가 사건의 시작 턴을 포착해 [⏳ 기록 중]에 걸어두고, 사건이 끝나는 순간 시작~끝 턴 원문을 통째로 읽어 표정, 제스처, 실제 대사("")가 살아있는 고밀도 로어북을 생성합니다.

로어북 키워드 + 256차원 벡터 RAG

별도의 유료 임베딩 API 설정 없이도 즉시 작동하는 한국어 특화 로컬 바이그램 벡터 엔진이 내장되어 있습니다. 현재 대화 맥락과 유사도가 높은 과거 사건만 골라 프롬프트에 자동 주입합니다.

다중 인물 관계도 · 약속 · 인벤토리

기계적인 {{char}} 표기 대신 대화에 등장하는 모든 캐릭터의 실제 이름으로 심리/관계 변화 궤적([STATE]), 미해결 목표와 약속([OPEN]), 보유 아이템([ITEMS])을 추적합니다.

듀얼 트랙 메모리 파이프라인

서브 API(Gemini Flash, Kimi 등 가성비 모델)를 활용해 본 채팅의 속도와 비용에 부담을 주지 않습니다.

Track 01 · 매 턴 감지

⏳ 사건 시작 & 종료 포착

진행 중인 사건이 여러 개 겹쳐도 각각 독립된 스레드로 추적하다가, 사건이 종료되면 해당 턴 구간의 대사만 핀셋 추출해 로어북으로 남깁니다.

Track 02 · N턴 주기

📜 상태창 갱신 & 대화 숨김

최신 버퍼(예: 2턴)를 보호하고 확정된 과거 턴을 요약하여 조각 슬롯과 관계/목표/인벤토리를 갱신한 뒤, 원문에는 [요약됨] 점선을 남기고 숨깁니다.

Track 03 · 프롬프트 주입

⚡ Chat History 직전 결합

본 채팅 전송 시 [전체 요약 + 벡터로 소환된 과거 사건 + 현재 상태창]을 채팅 내역 바로 위에 깔끔하게 삽입하여 완벽한 기억력을 유지합니다.

스마트 UX & 사용 꿀팁

유저의 클릭 횟수를 최소화하기 위해 세심하게 설계된 편의 기능들입니다.

🔖 책갈피 팝업 & 장면 선택 (< >)

각 메시지의 점 3개(...) 메뉴를 누르면 나오는 <(시작), >(끝) 버튼으로 원하는 구간만 콕 집어 요약하거나 사건 로어북으로 만들 수 있습니다. 어느 탭에서나 상단 책갈피를 당겨 실행하세요.

✨ 자동 저장 & 원클릭 롤백

번거로운 수동 저장 버튼 대신, 내용을 고친 뒤 사이드바를 닫거나 다음 채팅을 입력하면 즉시 자동 저장됩니다. 수정 중 마음에 들지 않으면 하단의 롤백 버튼으로 언제든 되돌릴 수 있습니다.

🔄 기존 채팅방도 처음부터 일괄 요약

이미 수십~수백 턴 진행된 채팅방이라도 걱정하지 마세요. 책갈피 메뉴의 [밀린 대화 처음부터 일괄 요약] 버튼 하나로 처음부터 차곡차곡 기억을 구축할 수 있습니다.
