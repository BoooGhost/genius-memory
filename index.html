Core Architecture

정교하게 분리된 두 개의 기억 체계.

상시 유지되어야 할 맥락과 필요할 때 꺼내 볼 디테일을 서로 다른 방식으로 처리합니다.

1 + 5Hierarchical Compression

계층형 전체 요약과 자동 숨김

최근 대화를 보호하는 버퍼를 제외한 확정된 과거 대화를 요약하여 5개의 조각 슬롯에 순차적으로 기록합니다. 5개의 조각이 모두 차면 하나의 통합 요약으로 재압축하며, 요약이 완료된 원본 메시지는 자동으로 숨김 처리되어 프롬프트 길이를 일정하게 유지합니다.

256Dim Vector Engine

무설정 내장 벡터 검색

별도의 임베딩 API 없이도 즉시 작동하는 한국어 바이그램 벡터 엔진을 탑재했습니다. 키워드 일치도와 코사인 유사도를 결합해 현재 대화와 관련된 과거 사건만 프롬프트에 주입합니다.

ParallelEvent Tracking

실시간 병렬 사건 감지기

매 턴 가벼운 감지기가 사건의 시작과 종료를 추적합니다. 여러 사건이 동시에 겹쳐 진행되어도 각각 독립된 스레드로 대기시켰다가, 사건이 끝나는 순간 해당 구간의 대사만 발라내어 표정과 대사가 살아있는 로어북으로 완성합니다.

MultiCharacter State

다중 인물 관계도 · 목표 · 인벤토리

기계적인 대명사 대신 대화에 등장하는 모든 인물의 실제 이름을 사용하여 심리 변화의 궤적(Prior → Trigger → Current), 미해결된 약속과 목표, 보유 아이템의 변동을 상시 갱신합니다.

Specifications

워크플로우 및 편의 사양.

서브 API 분리 운용
본 채팅 모델과 분리된 OpenAI 호환 서브 API(Gemini Flash, Kimi, DeepSeek 등)를 사용하여 본 채팅의 응답 속도와 비용에 영향을 주지 않고 백그라운드에서 기억을 처리합니다.
장면 핀셋 지정 (< >)
각 메시지의 더보기(...) 메뉴에 내장된 시작(<) 및 끝(>) 버튼으로 원하는 턴 구간만 정확히 지정하여 메인 요약을 실행하거나 개별 사건 로어북으로 생성할 수 있습니다.
기존 채팅방 일괄 요약
이미 길게 진행된 채팅방에서도 일괄 요약 실행 한 번으로 처음부터 보호 버퍼 직전까지의 모든 대화를 설정된 턴 단위로 나누어 순차 요약합니다.
프롬프트 주입 위치
전체 스토리 요약, 벡터로 소환된 과거 사건 기록, 그리고 현재 상태창(관계·목표·아이템)을 하나의 정돈된 컨텍스트 블록으로 묶어 채팅 내역(Chat History) 직전에 주입합니다.
